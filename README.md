# Venture Civil & Engineering Consultancy Services Website

A modern, high-performance, responsive website for **Venture Civil & Engineering Consultancy Services**, featuring luxury dark-mode aesthetics, custom gold accents, smooth animations, interactive BIM model comparisons, and interactive project showcases.

---

## 🚀 Live Preview / How to Run Locally

You can preview the website immediately using any of the methods below:

### Method 1: Python Built-in Server (Recommended & Instant)
Open Terminal in this directory and run:
```bash
python3 -m http.server 3000
```
Then visit: **[http://localhost:3000](http://localhost:3000)**

### Method 2: Node / npx serve
```bash
npx serve
```

### Method 3: VS Code / IDE Live Server
Right-click `index.html` and click **"Open with Live Server"**.

## ✨ Features & Animations Included

1. **Brand Identity**: Custom vector typography for **VENTURE CIVIL & ENGINEERING CONSULTANCY SERVICES** with interactive hover effects and the signature gold accent.
2. **Hero Section**: Dynamic typography layout with `// Civil & Structural Engineering & Consultancy Services`, smooth fade-up entry animations, and high-impact background imagery.
3. **Interactive BIM Comparison Slider**: Draggable split-screen slider comparing the 3D BIM Revit model directly with the constructed building.
4. **Interactive Projects Showcase**: 6 featured projects with modal dialogs, full image carousels, sector badges, and detailed case studies.
5. **Areas of Practice & Sectors**: 7 practice sectors (Residential, Multi-Residential, Commercial, Industrial, Civic, Aged Care, High-end) with sleek hover borders.
6. **Services Spectrum**: Pre-Construction, During Construction, and Post-Construction engineering services.
7. **Senior Team / Leadership**: High-resolution grayscale-to-color hover portrait cards with direct contact links.
8. **Contact Section & Modal**: Inquiries form with animated input states and one-click contact channels.
9. **Fully Responsive**: Mobile drawer navigation menu with smooth transitions, optimized for mobile, tablet, and 4K displays.

## 🌐 Deploying to the Web

This is a static site and can be deployed anywhere with zero configuration:

- **Netlify**: Drag and drop the `venture-civil-website` folder onto [Netlify Drop](https://app.netlify.com/drop).
- **Vercel**: Run `npx vercel` inside this folder or import via GitHub.
- **Cloudflare Pages**: Connect your repository or upload the folder in Cloudflare Pages dashboard.
- **GitHub Pages**: Push this folder to a GitHub repository and enable GitHub Pages in Settings.
